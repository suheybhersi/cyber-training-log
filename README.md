## Featured labs

- **[Vulnerability Discovery & Validation Lab](labs/vulnerability-discovery-validation/)** — Nmap enumeration and validation of two independent unauthenticated root-access paths against an isolated Metasploitable2 target, with evidence, impact, and remediation documented.
- **[Home Network Topology](labs/home-network-topology/)** — Cisco Packet Tracer home-network build covering addressing, wired/wireless connectivity, DHCP, and end-to-end connectivity testing.

## Repository approach

The aim of this repository is not to store every piece of study material.

Instead, it focuses on practical evidence that shows:

- what I built
- what I tested
- how I verified it
- problems I encountered
- how I investigated or resolved them
- what I learned from the exercise

This keeps the repository focused on demonstrable technical work rather than general course notes.
